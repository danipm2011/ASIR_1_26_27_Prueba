Hardware

Routers (ISR / ASR)

Interconnect different networks and determine the optimal path for data traffic using protocols like OSPF and BGP.

  • Models: Cisco 4000 ISR, Catalyst 8000
  • Usage: WAN links and branch offices
Catalyst Switches

Connect end devices within a Local Area Network (LAN) by forwarding frames using MAC addresses and VLANs.

  • Models: Catalyst 9200, 9300, Nexus
  • Usage: Access, distribution, and core layers
Firepower Firewalls

Inspect incoming and outgoing traffic by enforcing security policies, Intrusion Prevention (IPS), and VPN tunnels.

  • Models: Secure Firewall 1000, 3100
  • Usage: Advanced threat defense
Access Points

Extend wired networks with high-density Wi-Fi connectivity supporting Wi-Fi 6E and Wi-Fi 7 standards.

  • Models: Catalyst 9100, Cisco Meraki
  • Usage: Enterprise mobile coverage
